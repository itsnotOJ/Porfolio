# Asset Management

## Purpose

This document defines every visual asset used throughout the portfolio.

Every asset should have a permanent location inside the project.

Never duplicate assets.

Always reuse existing assets.

# Naming Convention

Use lowercase.

Separate words with hyphens.

Examples

hero-illustration-1.png

oxtago-dashboard.webp

nuuri-home-screen.webp

project-thumbnail-01.webp

---

# Optimization Rules

Compress images before deployment.

Never stretch images.

Preserve aspect ratios.

Use descriptive filenames.

Always use the Next.js Image component unless SVGs are imported as React components.

# Mercy Onyilo Portfolio

A modern, editorial-style portfolio built to showcase product design, frontend development, and illustration work.

---

## Purpose

This project is the official portfolio website for Mercy Onyilo.

The goal is to create a high-quality, responsive experience that accurately represents the approved Figma design while demonstrating strong frontend engineering practices.

The portfolio should communicate professionalism, attention to detail, and design thinking.

---

## Project Goals

- Showcase selected UX case studies.
- Showcase illustration work.
- Demonstrate frontend development skills.
- Provide recruiters and hiring managers with an easy way to understand my work.
- Maintain excellent accessibility and performance.
- Match the approved Figma as closely as possible.

# Design System

## Purpose

This document defines the visual language of the portfolio.

All UI should follow these guidelines to maintain consistency across every page and component.

If the approved Figma differs from these guidelines, the Figma always takes priority.

---

# Design Principles

The portfolio should feel:

- Modern
- Editorial
- Minimal
- Professional
- Spacious
- Illustration-first
- Carefully crafted

Every section should have a clear visual hierarchy.

Avoid visual clutter.

Whitespace is an intentional part of the design.

---

# Brand Personality

The experience should communicate:

- Confidence
- Precision
- Simplicity
- Craftsmanship
- Curiosity
- Professionalism

# Cards

Cards should:

- Maintain equal spacing
- Use consistent padding
- Scale slightly on hover
- Never distort images

---

# Images

Always preserve aspect ratio.

Never stretch.

Use optimized images.

Lazy load below-the-fold images.

---

# Icons

Use Lucide React icons.

Maintain consistent sizing.

Do not mix icon libraries.

---

# Animations

Animations should be subtle.

Preferred animations:

- Fade
- Slide
- Scale
- Marquee
- Reveal on scroll

Avoid:

- Bounce
- Spin
- Excessive motion

---

# Motion Guidelines

Duration

200ms–500ms

Easing

ease-out

Page transitions should feel smooth.

---

# Accessibility

Maintain WCAG AA contrast.

Visible keyboard focus.

Descriptive alt text.

Semantic HTML.

Keyboard navigation.

Respect reduced motion preferences.

# Project Specification

## Project

Mercy Onyilo Portfolio

## Purpose

Build a modern, responsive portfolio from the approved Figma design.

## Audience

- Recruiters
- Hiring Managers
- Startup Founders
- Creative Agencies

## Goals

- Showcase UI/UX projects
- Showcase illustrations
- Demonstrate frontend ability
- Encourage contact

## Pages

- Home
- About
- Selected Works
- Contact

## Responsive Breakpoints

Desktop:
1280px+

Tablet:
768–1279px

Mobile:
0–767px

# Deliverables

The completed portfolio should include:

- Responsive navigation
- Hero section
- About section
- Selected Works section
- Contact section
- Footer
- Mobile navigation
- Responsive layouts
- Smooth animations
- Optimized images
- Accessibility support
- Performance optimizations

# Success Criteria

The project is complete when:

- Every deliverable has been implemented.
- The design matches the approved Figma file.
- The site is fully responsive.
- Accessibility checks pass.
- Images are optimized.
- Performance is production-ready.
- All links work correctly.
- The portfolio is ready to deploy.
